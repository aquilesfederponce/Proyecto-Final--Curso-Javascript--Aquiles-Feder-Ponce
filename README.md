PROYECTO FINAL - CURSO JAVASCRIPT

Alumno: Aquiles Feder Ponce
Nombre del proyecto: Cafeteria Dublin

DESCRIPCIÓN:
Cafeteria Dublin es el nombre de una empresa dedicada a la venta de granos de café de especialidad de todo el mundo.
Para este proyecto decidí crear un e-commerce que simule el proceso completo desde la visualización de los productos
que ofrece el negocio, la implementación de un carrito de compras y que finalice en la compra del producto. Intente aplicar
todos los conocimientos obtenidos en el curso e implementados en las pre-entregas, las cuales me fueron de gran ayuda para llegar
al objetivo final. Utilice sass para darle un estilo completo y trate de organizar el proyecto lo mejor posible. Quedé muy contento
con el resultado. 

NOTA ADICIONAL DE FUNCIONAMIENTO: Cuando se encuentra en carrito.html, al apretar nuevamente el indicador de carrito, es decir el contador de items,
se despliega el resumen de compra con las acciones de compra y vaciado de carrito.
